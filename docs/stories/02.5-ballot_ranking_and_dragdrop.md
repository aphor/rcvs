# 02.5 Ballot ranking + drag/drop

Rankable ballot of picked beers. Part of [Epic 02](02-favorite_beer_frontend_mock.md). Depends on
[02.4](02.4-tasted_list_and_vote_button.md).

* `frontend/src/components/Ballot.jsx` — lists a card per picked beer, by default in the **reverse
  order they were picked**.
* `frontend/src/components/BallotCard.jsx` — up arrow (left) promotes rank, down arrow (right)
  demotes rank, X button removes the card. (X-removal confirmation modal is delivered in
  [02.6](02.6-cast_ballot_and_modals.md).)
* Cards are draggable to reorder on devices that support drag-and-drop via mouse **or** touch, using
  `@dnd-kit/core` + `@dnd-kit/sortable` (pointer + touch sensors). Up/down arrows remain the
  always-available baseline reorder. Add these deps to `frontend/package.json`.
* A floating "ADD MORE BEERS TO BALLOT" button on the top edge hides the ballot and shows the picker.
* Ballot order persists across reloads (mock session cookie).
