# 02.6 Cast ballot + confirmation modals

Finalize the ballot with confirmation gating and a persisted cast state. Part of
[Epic 02](02-favorite_beer_frontend_mock.md). Depends on
[02.5](02.5-ballot_ranking_and_dragdrop.md).

* `frontend/src/components/ConfirmModal.jsx` — reusable modal that forces a confirm/cancel choice.
* A "CAST BALLOT" button floats on the bottom edge of the ballot.
* The modal gates both **removing a beer** from the ballot (the X on a `BallotCard`) and **casting
  the ballot**; cancel is a no-op, confirm performs the action.
* On cast, set `ballotCast = true` in the mock session; ballot interaction is disabled and its
  buttons grayed out.
* The "ADD MORE BEERS TO BALLOT" button remains active but is relabeled "BROWSE BEERS".
* Cast state persists across reloads (mock session cookie).
