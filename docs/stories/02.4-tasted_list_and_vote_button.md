# 02.4 Tasted list + VOTE button

Accumulate tasted beers and expose the entry point to the ballot. Part of
[Epic 02](02-favorite_beer_frontend_mock.md). Depends on
[02.3](02.3-beer_picker.md).

* Beers chosen in the picker accumulate in `tastedBeers` and persist across reloads (mock session
  cookie).
* `frontend/src/components/VoteButton.jsx` — a "VOTE" button floating at the upper edge of the UI,
  visible only when `tastedBeers.length >= 1`.
* Clicking VOTE hides the beer picker and shows the ballot form (picker <-> ballot is local UI state
  within `/app`, not a route change).
