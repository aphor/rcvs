# 02.1 Frontend scaffold + mock data + session layer

Stand up the React/Vite app skeleton and the client-side data/session foundation that every other
02.x story builds on. Part of [Epic 02](02-favorite_beer_frontend_mock.md).

* `frontend/index.html` entry mounting `#root`; `frontend/src/main.jsx` renders the app inside a
  react-router `BrowserRouter`.
* `frontend/src/App.jsx` defines routes `/register`, `/login`, `/app`; redirects to `/register` when
  there is no active session.
* `frontend/src/data/beers.js` — fixture of ~60 beers, each `{ id, name, brewery, style, abv,
  imageUrl }`; `imageUrl` is a deterministic placeholder (e.g. `https://picsum.photos/seed/<id>/200`)
  with a local SVG fallback.
* `frontend/src/lib/session.js` — get/set helpers for `user`, `tastedBeers[]`, `ballot[]`, and the
  `ballotCast` flag, persisted under a single `localStorage` key that **stands in for the login
  session cookie**.
* `frontend/src/context/AppContext.jsx` — `useReducer` store that hydrates from `lib/session` on
  load and persists back on every change.
* `frontend/src/styles.css` — mobile-first base styles (floating-button + card scaffolding).
* App installs and runs: `npm --prefix frontend install && npm --prefix frontend run dev` serves on
  port 3000.
