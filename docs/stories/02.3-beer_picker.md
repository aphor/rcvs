# 02.3 Beer picker

Search-driven beer discovery with a preview pane. Part of
[Epic 02](02-favorite_beer_frontend_mock.md). Depends on
[02.1](02.1-frontend_scaffold_and_mock_data.md).

* `frontend/src/components/BeerPicker.jsx` — search input plus a preview pane container; the default
  view inside `/app`.
* `frontend/src/components/BeerPreview.jsx` — filters `data/beers.js` by name/brewery/style; shows a
  "too many choices" message until the match count is `<= 10`, then renders up to 10 result cards.
* `frontend/src/components/BeerResultCard.jsx` — shows the beer picture, beer name, and brewery;
  clicking it adds the beer to `tastedBeers` (via the store / `lib/session`).
* Adding a beer already in the tasted list is a no-op (no duplicates).
