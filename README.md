# Ranked Choice Voting System

A mobile-friendly web application demonstrating Ranked Choice Voting (RCV) for democratic decision-making.

## Features

- Mobile-responsive UI
- Ranked choice voting simulation
- Vote counting and results display
- Interactive ballot interface

## Technology Stack

- Python 3.14
- Flask (web framework)
- React.js (frontend)
- Mobile-first responsive design

## Getting Started

### Prerequisites

- Python 3.14+
- Node.js (for frontend development)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
```

2. Install Python dependencies:
```bash
pip install -r requirements.txt
```

3. Install frontend dependencies:
```bash
cd frontend
npm install
```

### Running the Application

1. Start the backend server:
```bash
python app.py
```

2. Start the frontend development server:
```bash
cd frontend
npm start
```
