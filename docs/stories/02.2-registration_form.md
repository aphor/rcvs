# 02.2 Registration form

Collect nominal user details and start the mock session. Part of
[Epic 02](02-favorite_beer_frontend_mock.md). Depends on
[02.1](02.1-frontend_scaffold_and_mock_data.md).

* `frontend/src/components/RegistrationForm.jsx` rendered at `/register`.
* Fields: firstname, lastname, mobile, phone, email — all required, with basic client-side validation
  (non-empty; email format).
* Submitting a valid form creates the mock session (`user` set via `lib/session`) and navigates to
  `/app`.
* With an active session, `/register` redirects to `/app`.
